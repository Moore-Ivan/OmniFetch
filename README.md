# OmniFetch - 万象抓取

## 项目介绍

OmniFetch 是一个功能强大的多协议下载管理器，支持 HTTP、HTTPS、FTP、SFTP、BitTorrent 和 M3U8 等多种协议，提供直观的图形界面和丰富的下载管理功能。

## 主要功能特性

### 支持的协议

- **HTTP/HTTPS**：标准网页文件下载
- **FTP**：文件传输协议，支持匿名和认证登录
- **SFTP**：安全文件传输协议，基于SSH
- **BitTorrent**：种子文件和磁力链接下载
- **M3U8/HLS**：流媒体分段下载

### 核心功能

- **多任务管理**：同时管理多个下载任务
- **任务控制**：支持暂停、继续、删除任务
- **自动协议检测**：根据URL自动识别下载协议
- **实时进度显示**：可视化下载进度条
- **速度监控**：实时显示下载速度
- **路径管理**：自定义保存路径，支持浏览选择
- **认证支持**：FTP/SFTP协议支持用户名密码认证
- **任务状态管理**：清晰显示任务状态（下载中、完成、失败、暂停、等待中）
- **搜索功能**：快速查找任务
- **全选功能**：批量操作任务
- **联系作者**：点击工具栏"联系作者"按钮，可在浏览器中查看作者联系方式和项目信息

### 用户界面

- **FlatLaf 外观**：基于 FlatLaf，内置亮色（Flat Light）与暗色（Flat Dark）主题，工具栏可一键切换，支持 HiDPI 缩放
- **响应式布局**：适配不同窗口大小
- **状态徽章**：直观显示当前协议类型
- **语义化配色**：不同状态使用不同颜色标识
- **表格视图**：清晰展示任务列表和详细信息，选中行高亮显示
- **工具栏按钮**：包含添加、暂停、继续、删除、全选、退出、联系作者等常用操作按钮

## 安装说明

### 环境要求

- Java 17 或更高版本
- 操作系统：Windows、macOS、Linux

### 从源码构建

1. **克隆项目**
   ```bash
   git clone <repository-url>
   cd OmniFetch
   ```
2. **构建项目**
   ```bash
   gradle shadowJar
   ```
   构建完成后，可执行jar文件会生成在 `build/libs/` 目录下。
3. **运行应用**
   ```bash
   java -jar build/libs/OmniFetch-x.x.x-all.jar
   ```

### 直接使用已构建的分发包

1. 从 `build/distributions/` 目录获取分发包（.zip 或 .tar）
2. 解压到任意目录
3. 运行 `bin/OmniFetch`（Linux/macOS）或 `bin/OmniFetch.bat`（Windows）

## 使用指南

### 基本操作

1. **添加下载任务**
   - 在"下载链接 / URL"输入框中输入下载地址
   - 选择保存路径
   - 对于FTP/SFTP协议，输入用户名和密码
   - 点击"添加"按钮
2. **管理下载任务**
   - **暂停**：选择任务后点击"暂停"按钮
   - **继续**：选择任务后点击"继续"按钮
   - **删除**：选择任务后点击"删除"按钮
   - **全选**：点击"全选"按钮选择所有任务
3. **查看任务信息**
   - 任务列表显示任务ID、文件名、进度、速度和状态
   - 进度列显示可视化进度条
   - 速度列显示当前下载速度
   - 状态列显示任务当前状态
4. **搜索任务**
   - 在右侧搜索框中输入关键词
   - 任务列表会实时过滤显示匹配的任务
5. **联系作者**
   - 点击工具栏"联系作者"按钮（位于"退出"按钮左侧）
   - 在默认浏览器中打开联系页面，查看作者联系方式和项目信息
6. **退出应用**
   - 点击"退出"按钮
   - 确认退出操作
   - 未完成的下载任务将被取消
7. **切换主题**
   - 点击工具栏右上角"深色主题"/"浅色主题"按钮，可在亮色与暗色外观之间即时切换

### 协议特定操作

#### FTP下载

- 支持匿名登录和认证登录
- 匿名登录默认用户名为"anonymous"

#### SFTP下载

- 默认用户名为"root"
- 需要输入正确的密码进行认证

#### BitTorrent下载

- 支持.torrent文件和磁力链接
- 自动解析种子文件

#### M3U8/HLS下载

- 自动处理分段下载
- 合并分段文件为完整视频

## 配置管理

配置文件位于程序根目录 `config/application.properties`（UTF-8）。程序每次启动时自动加载；若文件不存在则自动生成带中文注释的默认配置。

也可点击工具栏 **"高级配置"** 按钮打开图形化配置窗口：

- 配置项按"下载 / HTTP / FTP/SFTP / 插件"分组展示
- 每个数值项都有合理的最小/最大阈值（界面中通过数值调节器限制，保存与读取时也会自动钳制）
- **恢复默认**：将界面各项重置为默认值（需再点"保存当前"才会写盘）
- **保存当前**：校验通过后写入配置文件并即时生效（如线程池大小会热更新）

可调整的配置包括：

- 下载并发数、线程数、缓冲区、超时与刷新间隔
- HTTP 线程数与分片大小范围
- FTP/SFTP 连接池数量与超时
- 插件开关与插件目录

## 高级特性

### 连接池管理

- FTP和SFTP协议实现了连接池，提高连接复用率
- 自动管理连接的创建和释放

### 事件系统

- 基于事件总线的任务状态通知
- 实时更新UI界面

### 插件系统

- 支持扩展新的下载协议
- 可通过插件机制添加自定义功能

## 性能优化

- **多线程下载**：充分利用网络带宽
- **断点续传**：支持任务暂停后继续下载
- **智能连接管理**：根据网络状况调整连接数
- **内存优化**：合理使用缓冲区，减少内存占用

### 常见问题

1. **下载失败**
   - 检查网络连接
   - 确认URL格式正确
   - 对于FTP/SFTP，检查用户名和密码是否正确
2. **速度缓慢**
   - 检查网络带宽
   - 避免同时进行多个大文件下载
   - 检查服务器端限制
3. **应用崩溃**
   - 确保Java版本为17或更高
   - 检查系统内存是否充足
   - 查看日志文件获取详细错误信息
