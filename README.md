# OmniFetch - 万象抓取

## 项目介绍

OmniFetch 是一个功能强大的多协议下载管理器，支持 HTTP、HTTPS、FTP、SFTP、BitTorrent 和 M3U8 等多种协议，提供直观的图形界面和丰富的下载管理功能。

## 主要功能特性

### 支持的协议

- **HTTP/HTTPS**：标准网页文件下载，多线程分片加速
- **FTP**：文件传输协议，支持匿名和认证登录
- **SFTP**：安全文件传输协议，基于SSH
- **BitTorrent**：种子文件和磁力链接下载
- **M3U8/HLS**：流媒体分段下载

### 核心功能

- **多任务管理**：同时管理多个下载任务，并发数可配置
- **任务控制**：支持暂停、继续、删除任务，失败自动重试（次数可配置）
- **断点续传**：HTTP 多线程分片、FTP/SFTP 均支持暂停/失败后从已下载位置继续
- **限速**：支持全局下载限速与单任务限速（跟随全局/不限速/预设档位），下载中调整即时生效
- **自动协议检测**：根据URL自动识别下载协议
- **实时进度显示**：可视化进度条，百分比绘制在进度条内部
- **速度监控**：实时显示下载速度
- **路径管理**：保存路径统一在配置中管理，主界面"浏览…"选择后写回配置并即时生效
- **认证支持**：FTP/SFTP协议支持用户名密码认证
- **任务状态管理**：清晰显示任务状态（下载中、完成、失败、暂停、等待中）
- **搜索功能**：快速查找任务
- **全选功能**：批量操作任务
- **任务右键菜单**：打开文件、复制下载链接、暂停/继续、限速、删除、打开目录
- **联系作者**：点击工具栏"联系作者"按钮，可在浏览器中查看作者联系方式和项目信息
- **剪贴板自动检测**：自动识别系统剪贴板中的下载链接，主动提示是否立即下载
- **历史下载记录持久化**：程序退出后自动保存下载记录，重启后恢复任务列表（暂停/失败任务可继续，已完成任务可查看）
- **应用内自动更新**：检查新版本、下载安装包（支持暂停/后台下载/断点续传）、SHA-256 校验后自动启动安装
- **日志系统**：按天滚动记录到 `logs/` 目录，便于排查问题

### 用户界面

- **FlatLaf 外观**：基于 FlatLaf 的现代化跨平台 Swing 外观，支持 HiDPI 缩放
- **三态主题**：浅色 / 深色 / 跟随系统（自动检测操作系统深浅色并即时切换），主题选择持久化保存
- **响应式布局**：适配不同窗口大小
- **状态徽章**：直观显示当前协议类型
- **语义化配色**：不同状态使用不同颜色标识
- **表格视图**：清晰展示任务列表和详细信息，选中行高亮显示，进度百分比绘制在进度条内部
- **Toast 轻提示**：任务完成/失败、配置修改等操作以不打断式提示反馈
- **工具栏按钮**：包含添加、暂停、继续、删除、全选、检查更新、联系作者、退出等常用操作按钮

## 安装说明

### 环境要求

- **源码安装需要**：Java 17 或更高版本
- **软件安装支持**：Windows操作系统

### 源码安装（需要Java环境）

1. **克隆项目**
   ```bash
   git clone <repository-url>
   cd OmniFetch
   ```
2. **构建项目**
   ```bash
   gradle shadowJar
   ```
   构建完成后，可执行jar文件会生成在 `build/libs/` 目录下。
3. **运行应用**
   ```bash
   java -jar build/libs/OmniFetch-x.x.x-all.jar
   ```

### 软件安装（推荐，目前仅支持Windows）

对于普通用户，可以直接下载已编译好的Windows可执行文件：

1. **访问Release页面**
   - 访问项目GitHub Release页面：[https://github.com/Moore-Ivan/OmniFetch/releases](https://github.com/Moore-Ivan/OmniFetch/releases)
   - 下载Windows可执行文件（.exe格式）

2. **运行程序**
   - Windows: 双击 `OmniFetch-x.x.x.exe` 即可运行

3. **注意事项**
   - 软件安装包已包含所有依赖，无需额外配置Java环境
   - 支持一键安装，适合不熟悉Java环境的用户
   - 提供自动更新功能（如可用）

## 使用指南

### 基本操作

1. **添加下载任务**
   - 在"下载链接 / URL"输入框中输入下载地址
   - 保存路径行显示当前配置的保存目录：点击"浏览…"可修改（写回配置并即时生效），点击"打开"可在文件管理器中查看
   - 对于FTP/SFTP协议，输入用户名和密码
   - 点击"添加"按钮

2. **管理下载任务**
   - **暂停**：选择任务后点击"暂停"按钮
   - **继续**：选择任务后点击"继续"按钮
   - **删除**：选择任务后点击"删除"按钮
   - **全选**：点击"全选"按钮选择所有任务
   - **右键菜单**：右键点击任务可打开文件、复制下载链接、暂停/继续、设置限速、删除、打开所在目录
   - **双击**：双击任务行直接打开已下载的文件

3. **查看任务信息**
   - 任务列表显示任务ID、文件名、进度、速度和状态
   - 进度列显示可视化进度条（百分比绘制在进度条内部）
   - 速度列显示当前下载速度
   - 状态列显示任务当前状态

4. **搜索任务**
   - 在右侧搜索框中输入关键词
   - 任务列表会实时过滤显示匹配的任务

5. **限速**
   - **全局限速**：在"高级配置"中设置"全局下载限速"（0 为不限速）
   - **单任务限速**：右键任务 →"限速"子菜单，可选"跟随全局 / 不限速 / 预设档位"，下载中的任务调整即时生效

6. **联系作者**
   - 点击工具栏"联系作者"按钮（位于"退出"按钮左侧）
   - 在默认浏览器中打开联系页面，查看作者联系方式和项目信息

7. **退出应用**
   - 点击"退出"按钮
   - 确认退出操作
   - 未完成的下载任务将自动暂停，重启后可继续下载

8. **切换主题**
   - 点击工具栏主题按钮，可在浅色 / 深色 / 跟随系统三种模式间切换
   - "跟随系统"模式会自动检测操作系统深浅色并即时切换
   - 主题选择会持久化保存，重启后保持

9. **剪贴板自动下载**
   - 程序运行时会自动检测系统剪贴板中的下载链接
   - 检测到链接时会弹出确认对话框，询问是否立即下载
   - 可在"高级配置"中调整检测间隔或关闭此功能

10. **历史记录恢复**
    - 程序启动时会自动恢复历史下载记录
    - 恢复的任务会显示为暂停状态（FTP/SFTP任务可能需要输入密码）
    - 暂停/失败的任务可继续下载，已完成任务可查看文件或删除记录

11. **检查更新**
    - 点击工具栏"检查更新"按钮手动检查，启动后也会自动检查一次
    - 发现新版本后可在应用内直接下载安装包，支持暂停/继续与后台下载（下载期间可关闭对话框继续使用主界面）
    - 下载完成后自动进行 SHA-256 校验（发布页提供校验文件时）并启动安装程序
    - 也可点击"查看发布页"在浏览器中手动下载

### 协议特定操作

#### FTP下载

- 支持匿名登录和认证登录
- 匿名登录默认用户名为"anonymous"

#### SFTP下载

- 默认用户名为"root"
- 需要输入正确的密码进行认证

#### BitTorrent下载

- 支持.torrent文件和磁力链接
- 自动解析种子文件

#### M3U8/HLS下载

- 自动处理分段下载
- 合并分段文件为完整视频

## 配置管理

配置文件位于程序根目录 `config/application.properties`（UTF-8，带中文分组注释）。程序每次启动时自动加载；若文件不存在则自动生成默认配置。程序运行时会监视配置文件（约 5 秒轮询一次），手动修改并保存后无需重启即可生效。

也可点击工具栏 **"高级配置"** 按钮打开图形化配置窗口：

- 配置项按"下载 / HTTP / FTP-SFTP / 插件 / 剪贴板"分组展示，并显示配置文件的实际路径
- 每个数值项都有合理的最小/最大阈值（界面中通过数值调节器限制，保存与读取时也会自动钳制）
- 目录型配置项（保存路径）以文本框 + "浏览…"按钮呈现，显示当前实际保存路径，可直接编辑
- **恢复默认**：确认后将界面各项重置为默认值，并直接写盘生效
- **保存当前**：校验通过后写入配置文件并即时生效（如线程池大小、限速等会热更新）

### 配置项一览

**下载配置**

| 配置项 | 说明 | 默认值 | 范围 |
| --- | --- | --- | --- |
| download.maxConcurrentTasks | 最大并发任务数（个） | 5 | 1 ~ 20 |
| download.maxThreads | 最大线程数（个） | 20 | 1 ~ 256 |
| download.bufferSize | 缓冲区大小（字节） | 262144 | 4096 ~ 16777216 |
| download.connectTimeoutSec | 连接超时（秒） | 15 | 1 ~ 300 |
| download.progressIntervalMs | 进度更新间隔（毫秒） | 200 | 50 ~ 5000 |
| download.flushIntervalMs | 磁盘刷新间隔（毫秒） | 10000 | 1000 ~ 120000 |
| download.maxRetryCount | 失败自动重试次数（次） | 3 | 0 ~ 10 |
| download.m3u8Concurrent | M3U8分片并发数（个） | 8 | 1 ~ 16 |
| download.globalSpeedLimitKB | 全局下载限速（KB/s） | 0（不限速） | 0 ~ 1048576 |
| download.autoOpenFolder | 完成后自动打开目录 | false | true / false |
| download.defaultSaveDir | 保存路径 | downloads | 目录路径 |

**HTTP配置**

| 配置项 | 说明 | 默认值 | 范围 |
| --- | --- | --- | --- |
| http.maxThreads | HTTP最大线程数（个） | 16 | 1 ~ 128 |
| http.minChunkSize | 最小分片大小（字节） | 5242880 | 65536 ~ 104857600 |
| http.maxChunkSize | 最大分片大小（字节） | 52428800 | 1048576 ~ 536870912 |
| http.userAgent | User-Agent | Mozilla/5.0 (MultiProtocolDownloader/2.0) | 文本 |

**FTP/SFTP配置**

| 配置项 | 说明 | 默认值 | 范围 |
| --- | --- | --- | --- |
| ftp.maxConnections | 最大连接数（个） | 10 | 1 ~ 50 |
| ftp.connectionTimeoutSec | 连接超时（秒） | 30 | 1 ~ 300 |
| ftp.idleTimeoutSec | 空闲超时（秒） | 60 | 5 ~ 600 |

**插件配置**

| 配置项 | 说明 | 默认值 |
| --- | --- | --- |
| plugin.enabled | 是否启用插件 | true |
| plugin.dir | 插件目录 | plugins |

**剪贴板配置**

| 配置项 | 说明 | 默认值 | 范围 |
| --- | --- | --- | --- |
| clipboard.monitorEnabled | 自动识别剪贴板下载链接 | true | true / false |
| clipboard.pollIntervalMs | 剪贴板检测间隔（毫秒） | 1000 | 200 ~ 10000 |

> **保存路径说明**：`download.defaultSaveDir` 支持绝对路径或相对路径（相对路径按程序根目录解析，默认 `downloads` 即程序根目录下的 downloads 文件夹）。主界面"浏览…"按钮选择目录后会写回该配置并即时生效；目录在首次下载时自动创建。

## 高级特性

### 连接池管理

- FTP和SFTP协议实现了连接池，提高连接复用率
- 自动管理连接的创建和释放

### 事件系统

- 基于事件总线的任务状态通知
- 实时更新UI界面

### 插件系统

- 支持扩展新的下载协议
- 可通过插件机制添加自定义功能

### 限速体系

- **全局限速**：基于令牌桶算法，通过 `download.globalSpeedLimitKB` 配置（0 为不限速）
- **单任务限速**：任务右键菜单"限速"子菜单可选"跟随全局 / 不限速 / 预设档位（512KB/s ~ 10MB/s）"
- 任务级限速优先于全局限速，下载中的任务调整后即时生效

### 断点续传

- **HTTP 多线程分片**：`.partmeta` 侧车文件记录总分片参数与各分片完成字节，定期原子刷盘；续传时各分片携带 Range 头从已下载位置继续
- **FTP/SFTP**：下载写入 `.part` 文件，FTP 使用 `REST` 指令、SFTP 使用 RESUME 模式续传，完成后原子重命名为最终文件
- **应用内更新**：安装包下载支持暂停/继续与断点续传

### 应用内自动更新

- 工具栏"检查更新"手动检查，启动后延迟自动检查一次
- 更新检查双链路：优先 GitHub API，受限流或网络异常时自动降级到网页端解析
- 安装包下载支持**后台下载**（关闭更新窗口后主界面按钮实时显示进度）、暂停/继续、断点续传
- 下载完成后自动进行 **SHA-256 校验**（发布页提供 `.sha256` 资产时；校验值不可得时降级为大小校验不阻断），通过后自动启动安装程序
- 全部链路使用信任本机证书环境的 HTTPS 配置，兼容系统代理

### 剪贴板智能检测

- 自动识别系统剪贴板中的下载链接
- 仅对受支持的协议（HTTP/HTTPS/FTP/SFTP/BitTorrent/M3U8）进行提示
- 同一链接只提示一次，避免重复打扰
- 可在高级配置中调整检测间隔或完全关闭此功能

### 历史下载记录持久化

- **自动保存**：程序退出时自动保存下载记录到 `config/history.json`
- **恢复功能**：重启后自动恢复历史任务（COMPLETED/FAILED 保留原状态，其余一律暂停）
- **密码保护**：FTP/SFTP密码不落盘，恢复后继续时需重新输入
- **错误保留**：失败任务保留错误信息，可查看具体失败原因
- **记录管理**：最多保存1000条记录，超出时自动删除最旧已完成记录
- **损坏恢复**：JSON文件损坏时自动备份为 `.bad-时间戳` 并重建空历史

### 日志系统

- 日志按天滚动写入 `logs/` 目录（`app-yyyy-MM-dd.log`），同时输出到控制台
- 记录下载、配置加载、更新检查等关键事件与异常堆栈，便于排查问题

## 性能优化

- **多线程下载**：充分利用网络带宽
- **断点续传**：支持任务暂停后继续下载
- **智能连接管理**：根据网络状况调整连接数
- **内存优化**：合理使用缓冲区，减少内存占用
- **历史记录优化**：异步节流保存，避免频繁写盘影响性能
- **界面增量刷新**：任务表格按变更单元格增量更新并节流合并，避免全量重建带来的闪烁

### 常见问题

1. **下载失败**
   - 检查网络连接
   - 确认URL格式正确
   - 对于FTP/SFTP，检查用户名和密码是否正确

2. **速度缓慢**
   - 检查网络带宽
   - 检查是否设置了全局或单任务限速
   - 避免同时进行多个大文件下载
   - 检查服务器端限制

3. **应用崩溃**
   - 确保Java版本为17或更高
   - 检查系统内存是否充足
   - 查看 `logs/` 目录下的日志文件获取详细错误信息

4. **剪贴板提示不出现**
   - 确认剪贴板内容为单个下载链接（非多行文本或超长文本）
   - 检查"高级配置"中"自动识别剪贴板下载链接"是否已启用
   - 尝试复制其他支持的链接（如HTTP直链）

5. **历史记录恢复问题**
   - 确保程序有读写 `config/` 目录的权限
   - 如果历史记录损坏，程序会自动备份并重建
   - FTP/SFTP任务恢复后需要重新输入密码才能继续

6. **检查更新/更新下载失败**
   - 更新检查与安装包下载均需访问 GitHub（API 与资产 CDN）
   - 国内网络环境下请检查：系统代理是否开启、hosts 中是否残留失效的 GitHub 加速条目、防火墙是否放行
   - 可在更新窗口点击"查看发布页"手动下载安装包
